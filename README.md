Machine Learning project to predict student exam marks using Python.
# Student Performance Prediction System

## Project Overview
This project uses Machine Learning to predict student exam scores based on study hours, attendance, previous examination scores, and completed assignments.

## Objectives
- Predict student exam marks using regression algorithms.
- Visualize student data using graphs.
- Compare Linear Regression and Random Forest Regression.
- Develop an interactive web application using Gradio.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Gradio

## Machine Learning Algorithms
1. Linear Regression
2. Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Dataset
The initial version uses a synthetically generated dataset of 500 sample student records for learning and demonstration.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Train and evaluate the models.
4. Launch the Gradio application to test predictions.

## Limitations
The initial dataset is synthetic. Real-world performance must be validated using an appropriate real student dataset.
